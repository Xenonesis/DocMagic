# Accessibility Audit Plan (WCAG 2.1 AA)

## Tools

- Axe DevTools
- Lighthouse Accessibility
- Screen reader (NVDA/VoiceOver)

## Checks

- Semantics: headings, landmarks, roles
- Forms: labels, errors, descriptions
- Keyboard: tab order, focus management
- Contrast: text/icons meet AA
- Motion: reduced motion alternatives
- Media: captions/alt text
