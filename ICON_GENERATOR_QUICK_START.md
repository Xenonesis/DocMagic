# Icon Generator - Quick Start Guide

## 🚀 Getting Started in 3 Easy Steps

### Step 1: Navigate to Icon Generator
- Click **"Icon"** in the main navigation menu, OR
- Visit `/icon` directly, OR
- Click the **Icon card** on the homepage

### Step 2: Describe Your Icon
Enter a clear description of what you want:
- ✅ Good: "A modern rocket launching into space with blue and orange colors"
- ✅ Good: "Minimalist coffee cup icon with steam rising"
- ✅ Good: "3D shield with lock symbol for security app"
- ❌ Avoid: "icon" (too vague)
- ❌ Avoid: "something cool" (not specific)

### Step 3: Customize & Generate
1. Choose a **style** (Flat, 3D, Gradient, etc.)
2. Select a **size** (256px, 512px, or 1024px)
3. Pick **colors** (Vibrant, Pastel, or Custom)
4. Click **"Generate Icons"**

That's it! Your icons will appear in seconds. ✨

## 💡 Pro Tips

### Writing Great Descriptions

**Be Specific**
- ✅ "Round icon with a blue envelope and red notification badge"
- ❌ "Email icon"

**Mention Colors**
- ✅ "Green checkmark inside a white circle"
- ❌ "Checkmark"

**Describe the Mood**
- ✅ "Friendly robot with a smile for a chatbot app"
- ❌ "Robot"

**Add Context**
- ✅ "Shopping cart with items for an e-commerce app"
- ❌ "Cart"

### Size Selection

**256x256** - Small Icons
- Use for: Favicons, small UI elements
- Best for: Simple designs with few details

**512x512** - Standard Icons
- Use for: App icons, social media profiles
- Best for: Most use cases

**1024x1024** - High Resolution
- Use for: Logos, detailed graphics, print
- Best for: Complex designs with details

### Getting Better Results

1. **Start Simple**: Test with simple descriptions first
2. **Iterate**: Regenerate if not perfect
3. **Be Patient**: Complex descriptions take longer
4. **Try Variations**: Different styles can yield different results
5. **Use Examples**: Reference existing icons in your description

## ❓ Troubleshooting

### Icons Not Generating?
- Check your internet connection
- Verify description is not empty
- Try a simpler description
- Check if you've reached free tier limit

### Icons Look Different Than Expected?
- Try regenerating with modified description
- Change the style selection
- Adjust color scheme
- Be more specific in description

### Can't Download Icon?
- Sign in to your account (required for downloads)
- Check browser download permissions
- Try a different browser
- Contact support if issue persists

### Generation Taking Too Long?
- Complex descriptions may take 5-10 seconds
- Check server status
- Try during off-peak hours
- Simplify your description
