# More Page - User Guide

## Welcome to the More Documents Section! 🎉

This guide will help you navigate and use all 12 new document types available in the "More" section.

## How to Access

### Method 1: Navigation Menu
1. Look for the **"More"** item in the navigation menu (with a ➕ icon)
2. Click it to visit the main More page at `/more`

### Method 2: Homepage
1. Scroll to the "Choose Your Document Type" section on the homepage
2. Click the **"Explore More Types"** button at the bottom

### Method 3: Direct URL
- Navigate directly to: `https://your-domain.com/more`

---

## 📋 Available Document Types

### 1. 💳 Business Cards
**Best for:** Networking, professional contacts

**Quick Start:**
1. Go to `/more/business-card`
2. Fill in your personal information (name, title, company)
3. Add contact details (email, phone, website)
4. Choose a layout style (Modern, Classic, Minimal, or Creative)
5. Customize colors
6. Generate QR code for easy contact sharing
7. Preview and download

**Pro Tips:**
- Use the QR code feature to share your contact info instantly
- Try different layouts to match your brand
- Modern layout works great with QR codes

---

### 2. 📄 Flyers & Posters
**Best for:** Events, promotions, announcements

**Quick Start:**
1. Go to `/more/flyer`
2. Choose template style (Event, Sale, Announcement, Business)
3. Select size (Letter, A4, or Poster)
4. Write your main title and subtitle
5. Add description and call-to-action
6. Customize colors
7. Preview and download

**Pro Tips:**
- Use contrasting colors for better visibility

### 3. 📝 Contracts & Agreements

## 🔧 Troubleshooting

### Preview Not Updating?
- Check if you've filled required fields
- Switch tabs back and forth
- Refresh the page if needed

### Download Not Working?
- Ensure you're in the Preview tab
- Check browser popup settings
- Try a different browser

### Colors Not Showing?
- Verify color picker selections
- Try entering hex codes manually
- Clear browser cache if needed

### Mobile Issues?
- Rotate device for better view
- Use landscape for larger previews
- Tap carefully on small elements
