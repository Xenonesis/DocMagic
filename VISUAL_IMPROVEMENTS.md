## Animation Timeline

### Page Load Sequence:
```
0ms:    Hero section fades in
100ms:  Quick Start Guide slides up
200ms:  Document Type cards stagger in (100ms each)
700ms:  Quick Navigation items stagger in (50ms each)
1000ms: Features section slides in
1300ms: Testimonials fade in
1600ms: Final CTA fades in
```

### Hover Animations:
```
Cards:      Scale 1.0 → 1.05 (300ms)
Icons:      Scale 1.0 → 1.1 + Rotate (300ms)
Buttons:    Scale 1.0 → 1.05 + Glow (300ms)
Text:       Color → Gradient (300ms)
```

### Background Animations:
```
Orbs:       Float up/down (6s loop)
Gradients:  Shift position (4s loop)
Mesh:       Subtle movement (12s loop)
```

## Responsive Breakpoints

### Mobile (< 640px):
```
- 1 column layout
- Larger touch targets
- Simplified animations
- Hidden decorative elements
- Stacked CTAs
```

### Tablet (640px - 1024px):
```
- 2 column layout
- Medium spacing
- Full animations
- Some decorative elements
- Side-by-side CTAs
```

### Desktop (> 1024px):
```
- 3-6 column layout
- Generous spacing
- All animations
- All decorative elements
- Enhanced hover effects
```

## Color Usage Guide

### Document Types:
- **Resume**: Blue (bolt-gradient)
- **Presentation**: Orange (sunset-gradient)
- **Cover Letter**: Green (forest-gradient)
- **CV**: Purple (cosmic-gradient)
- **Diagram**: Cyan (ocean-gradient)

### UI Elements:
- **Primary CTA**: Blue gradient
- **Secondary CTA**: Outline with hover
- **Success**: Green
- **Warning**: Amber
- **Error**: Red
- **Info**: Blue

### Backgrounds:
- **Light Mode**: Cream/beige tones
- **Dark Mode**: Deep blacks with subtle gradients
- **Glass Effect**: Semi-transparent with blur

## Typography Scale

### Display (Hero):
```
Mobile:  text-3xl (30px)
Tablet:  text-5xl (48px)
Desktop: text-8xl (96px)
```

### Headings:
```
H2: text-2xl → text-4xl → text-6xl
H3: text-xl → text-2xl → text-3xl
H4: text-lg → text-xl → text-2xl
```

### Body:
```
Base:  text-sm → text-base → text-lg
Large: text-base → text-lg → text-xl
```

## Spacing System

### Section Padding:
```
Mobile:  py-12 (48px)
Tablet:  py-16 (64px)
Desktop: py-20 (80px)

```

### Card Padding:
```

```
